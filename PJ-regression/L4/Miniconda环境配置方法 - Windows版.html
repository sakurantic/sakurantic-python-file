1.3 在 Anaconda Prompt 中配置 AP1226 环境

在 Windows 系统中，我们不使用系统自带的 cmd 或 PowerShell，而是使用 Anaconda 提供的专用命令行工具。

点击电脑左下角的开始菜单，在搜索栏中输入anaconda Prompt，找到并打开 Anaconda Prompt。


在打开的黑底白字窗口中，依次输入以下命令。你可以复制下列命令，在 Anaconda Prompt 窗口中单击鼠标右键即可粘贴（或者使用 Ctrl + C 复制，Ctrl + V 粘贴），回车执行完成后，再复制下一个命令。

1.3.1 创建 AP1226 环境

由于在 Anaconda Prompt 中默认已经初始化，我们直接运行环境创建命令：

conda create -n AP1226 python=3.8.13 pytorch==1.13.1 torchvision==0.14.1 torchaudio==0.13.1 cpuonly numpy scipy scikit-learn pandas seaborn matplotlib opencv -c https://conda.anaconda.org/pytorch -c https://conda.anaconda.org/conda-forge --strict-channel-priority --solver=libmamba

此时会提示需要确认（如下图所示），输入 y 后回车，或直接按回车键即可。


回车后会执行并完成 AP1226 环境所需包的下载和安装。到出现如下图所示的 done 并且重新出现光标时，说明环境已经安装成功。

X. 补充阅读

X.1 为什么需要Miniconda？它和Python的关系是什么？

Python 是一门编程语言，安装后你只有一个解释器。但实际工作中，你几乎总是需要第三方库（比如 NumPy、pandas、TensorFlow），而管理这些库会遇到几个棘手的问题：

  • 依赖冲突：项目 A 需要 numpy 1.21，项目 B 需要 numpy 1.24，两者无法共存于同一个 Python 环境
  • 安装繁琐：科学计算库（如 scipy、scikit-learn）依赖大量底层 C/Fortran 库，用 pip 安装经常失败或需要手动配置编译环境
  • 环境污染：所有库装在一起，不同项目互相干扰。如果以后要删除某个项目，无法确定需要删除哪些包

在AP1226这门课程中，我们专门在conda中创建了AP1226这个环境。这样一来，本课程所需要的全部库都安装在AP1226环境中，且专门用于执行本课程的代码。课程结束后，你完全可以自行删除AP1226环境，而不影响到电脑上其他依赖Python运行的程序。当你们进入大学以后，不同的课程使用的软件包、第三方依赖库肯定会有所不同。合理地使用Miniconda等包管理工具，将减少你在配环境上浪费的时间
